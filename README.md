# Ecommerce Backend - Node.js + MongoDB + JWT

Backend de tienda online desarrollado con Node.js, Express y MongoDB.

## Funcionalidades

- Registro e inicio de sesión con JWT
- Roles de usuario (cliente / diseñador)
- Publicación de productos
- Subida de imágenes
- Carrito de compras
- Agregar, eliminar y modificar productos en carrito

## Tecnologías

- Node.js
- Express
- MongoDB
- Mongoose
- JWT
- Multer

## servidor corre en:
http://localhost:3000

##Variables de entorno (.env)
PORT=3000
MONGO_URI=tu_conexion
JWT_SECRET=tu_clave_secreta
